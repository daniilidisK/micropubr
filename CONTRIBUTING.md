# Contributing to micropubr

Thanks for helping improve micropubr. Bug reports, documentation fixes
and pull requests are all welcome.

## Reporting a bug

Open an issue at <https://github.com/daniilidisK/micropubr/issues> using
the bug report template. Please include a minimal reproducible example
(ideally with `reprex::reprex()`), built on a small or public dataset
such as `data(GlobalPatterns, package = "phyloseq")`, plus your
[`sessionInfo()`](https://rdrr.io/r/utils/sessionInfo.html).

## Development setup

``` r

# Install dependencies, including Bioconductor ones (phyloseq, DESeq2, ...)
install.packages(c("devtools", "BiocManager"))
devtools::install_dev_deps(dependencies = TRUE)

devtools::load_all()      # load the package from source
devtools::document()      # regenerate man/ and NAMESPACE from roxygen
devtools::test()          # run the test suite
devtools::check()         # full R CMD check
```

Never edit `NAMESPACE` or `man/*.Rd` by hand; they are generated by
roxygen2 (markdown enabled).

## Tests

- Tests use testthat (3rd edition) and live in `tests/testthat/`. Run
  them with `devtools::test()`, or a single file with
  `devtools::test(filter = "alpha")`.
- Shared fixtures (`make_test_ps()`, `make_da_df()`) are in
  `tests/testthat/helper-fixtures.R`; use them instead of downloading
  data.
- Guard optional dependencies with `skip_if_not_installed("pkg")`.
- Visual regression tests use vdiffr:
  `vdiffr::expect_doppelganger("name", p)`. Snapshots are stored in
  `tests/testthat/_snaps/`. After an intentional visual change, review
  and accept them with
  [`testthat::snapshot_review()`](https://testthat.r-lib.org/reference/snapshot_accept.html)
  and commit the updated SVGs. CI uploads changed snapshots as an
  artifact when a check fails.
- Test error conditions by class, not message:
  `expect_error(mp_alpha(ps, group.by = "Nonexistent"), class = "micropubr_bad_var")`.

## Code conventions

- **One verb family.** User-facing functions are `mp_*()` verbs
  ([`mp_alpha()`](https://daniilidisk.github.io/micropubr/reference/mp_alpha.md),
  [`mp_ordination()`](https://daniilidisk.github.io/micropubr/reference/mp_ordination.md),
  …). Internal helpers start with `.mp_` and are documented with
  `@noRd`.

- **Shared argument names.** Reuse the existing names rather than
  inventing new ones:

  - `object`: the input `phyloseq` object;
  - `group.by` (and `facet.by`, `color.by`, …): metadata column names;
  - `palette`: a micropubr palette name or a vector of colours;
  - `theme`: a ggplot2 theme (defaults come from
    [`mp_set_defaults()`](https://daniilidisk.github.io/micropubr/reference/mp_set_defaults.md));
  - `font.size`, `plot.title`, `plot.subtitle`, `plot.caption`;
  - `return.data = TRUE`: return the tidy data frame behind the plot;
  - `interactive = TRUE`: return a plotly widget instead of a ggplot;
  - `...`: forwarded to the primary geom. Argument names use `dot.case`.

- **Return a plain `ggplot`** (or `patchwork`) so users can extend it
  with `+`. Base-graphics exceptions
  ([`mp_chord()`](https://daniilidisk.github.io/micropubr/reference/mp_chord.md),
  [`mp_circos()`](https://daniilidisk.github.io/micropubr/reference/mp_circos.md))
  return their data invisibly.

- **Errors** are raised with
  [`rlang::abort()`](https://rlang.r-lib.org/reference/abort.html) and a
  `micropubr_*` condition class so they can be caught and tested
  reliably:

  ``` r

  rlang::abort(
    sprintf("`%s` is not a column of sample_data().", group.by),
    class = "micropubr_bad_var"
  )
  ```

  Use [`rlang::warn()`](https://rlang.r-lib.org/reference/abort.html) /
  [`rlang::inform()`](https://rlang.r-lib.org/reference/abort.html) for
  other conditions.

- **Optional packages** belong in `Suggests` and are checked at run time
  with `.mp_require("pkg", "What needs it", bioc = TRUE/FALSE)`, which
  raises a `micropubr_missing_dependency` error with an install hint.

- Colours must stay colourblind-safe; new palettes should be added to
  `R/mp_palette.R` and listed by
  [`mp_palettes()`](https://daniilidisk.github.io/micropubr/reference/mp_palettes.md).

- Follow the [tidyverse style guide](https://style.tidyverse.org/):
  two-space indents, `<-` for assignment, lines of 80 characters or
  fewer.

## Pull requests

1.  Fork the repository and create a branch from `main`.
2.  Add or update tests and roxygen documentation for your change.
3.  Add a bullet to the top section of `NEWS.md`.
4.  Make sure `devtools::check()` passes locally with no new errors,
    warnings or notes.
5.  Open the pull request; GitHub Actions runs R CMD check on macOS,
    Windows and Linux, test coverage, BiocCheck and a pkgdown build.
