# Cell-style theme (boxed panels, slightly larger type)

Cell-style theme (boxed panels, slightly larger type)

## Usage

``` r
mp_theme_cell(font.size = 10, base.family = "")
```

## Arguments

- font.size:

  Base font size in points. Defaults to the `micropubr.font.size` option
  (11).

- base.family:

  Font family. Defaults to "" (device default).

## Value

A `ggplot2` theme object.
